# Sahan

A modern restaurant site for a dining room on Lido Road, Mogadishu. The copy is English. The photographs are real plates and a real dining room.

## Pages

- Home
- Menu
- About
- Contact
- Visit, with a table request

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack

Next.js, React, and Tailwind CSS.
